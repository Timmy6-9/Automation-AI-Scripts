<h2>AI Automation for Windows Start-Up</h2>

My local AI scripts, one that runs using task scheduler when I login to my PC on work days and another for running as a stand-alone script.

Also includes a docker compose stack for open webui as a frontend for tooling/chats and searxng for locally hosted web searching.

If you want to use this yourself you'll need to build or download a release of llama.cpp for the hardware you're using as well as modifying the llama-server arguments for your hardware and preferred model.
